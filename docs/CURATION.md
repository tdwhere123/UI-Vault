# 收录规则

目标是有用、具有设计辨识度的素材库，不是下载数量榜。

- 一条对应一个独立体验：完整组件、完整区块、页面或完整图标系列。内部原语、配色、尺寸、框架版本、别名不另计。
- 原件、运行适配、依赖、许可各自可追溯。免费展示不等于允许把源码作为素材再分发；许可不清则不发布源码包。
- 只有实际打开并验证对应视觉/核心交互的条目才进入库存。构建通过、源码存在或截图存在不能替代运行验收。
- 截图必须来自真实运行页面，可裁去纯背景，但不得伪造上游效果。静态展示不标成动画，模拟数据不标成真实后台。
- 主类只按用途：Agent与对话、输入与选择、导航与组织、数据与状态、展示与媒体、产品与营销、视觉与动效。完整图标系列独立入口。
- 材质与风格放 `styleTags`；操作方式放 `interactionTags`；跨用途工作流放 `purposeTags`，例如 Agent工作流。页面/区块/组件属于 `format`，来源属于 `source`。
- 列表使用本地真实 WebP 封面与轻目录，不能重新塞入同时运行的组件 iframe。完整互动仅在详情加载；关详情或切源码后释放。
- 新条目须附图片、细分依赖及完整源码包。不要因数量目标降低设计质量或保留重复、空白、缺图、不可播放演示。

发布前：`npm run build`，导出检查，真实桌面/手机抽样与新增条目逐项验收。CI完成后核线上 `version.json`，未确认上线就不报告已交付。
