# UI Vault：20 件素材图鉴样板

此目录为首批20件图鉴主入口；没有执行200+扩充。Pages发布会将旧图库完整保留在 `legacy/`，不删除旧素材。旧 archive、inventory、gallery 和历史证据保持原样。

## 运行
从本目录执行 `python3 -m http.server 4173 --bind 0.0.0.0`，打开 http://localhost:4173 。无安装依赖，无外部 CDN；不要直接用 file:// 打开（浏览器会阻止 JSON 读取）。

## 内容与边界
20个来源明确、身份不同的真实HTML组件/页面区块，当前来自HyperUI。表单、交互、导航、数据展示、营销区块都有覆盖，未用深浅色或框架变体凑数。完整页面暂未纳入。

图鉴壳参考并保留了HyperUI MIT侧栏示例原件 `originals/shell-side-menu.html`；目录样式与交互是新的适配实现，未复制LeiBox代码，也未继续使用Neiki。不是声称复用了完整现成图鉴应用。

`originals/`保留逐项HTML原件、原站编译CSS和演示脚本及MIT许可。`previews/`内嵌已保存的CSS及演示脚本，并做默认亮色和安全隔离适配。`assets/component.css`移除原CSS远程Google字体导入，改用系统后备字体，原始CSS不改动。iframe保持不透明来源，内嵌依赖避免CSP self与sandbox冲突。预览不联网、不发送表单；导航、标签页等纯样式范例明确标为静态，不暗示实现后台业务。SVG图标随上游MIT示例保留，未采集第三方照片。

每个条目一个身份，搜索覆盖同一份 `items.json` 的全部素材。详情并列预览、源码、依赖和上游来源，版本信息收起显示。SHA不作为前台主内容。

## 下一步（须样板确认）
确认布局、分类和详情体验后，合并旧有素材到统一模型，补预览与缺失依赖，并从许可核实来源扩充200+。候选网站、无素材占位、重复版本均不计入有效条目。不得将20样板说成200完成。

此目录是当前图鉴入口。旧版暂保留在legacy/供取用；后续统一数据后再决定退役旧入口，不继续长期叠层。

`planning/source-candidates.json` 是20个待核实来源网站清单，不是已收录素材、不计入20或200统计。

每个详情的下载源码包包含未改动原件、可直接打开的独立预览、共享依赖副本、MIT许可及使用说明。原始HTML自身保留上游绝对路径，因此直接体验请选择包内preview.html。

预览适配增加垂直居中，小控件缩略画布380px，大区块600px；手机进一步收窄。此变化仅影响预览，不修改上游原件。
