# UI Vault · 精选界面素材

当前24个去重条目：**4件精选 + 20件基础素材**。首页精选不是简单控件堆数量：Looseleaf纸张便笺看板、手绘翻面词卡，Magic UI透视光束空间、双层轨道环绕。基础20保留在次级入口。尚未完成后续200+目标。

## 前端与交互
独立实现中性紧凑图鉴前端，不复制LeiBox代码。桌面分类导航与三列卡片；手机单列、折叠菜单/筛选；详情使用可直达hash链接，返回保留筛选与滚动。原始组件与预览适配分开，展示缩放有标注。

## 本地运行与发布
使用静态HTTP服务打开本目录；托管工作环境使用`sites-preview`。不支持直接file://打开图库JSON。Pages通过仓库`scripts/export-pages.mjs`发布根入口，旧图库和70份源码包保留在`legacy/`，不删除原始archive。

## 素材与下载
- 基础素材：`originals/`为上游原件，`previews/`为声明的预览适配，`bundles/`为逐项源码包。
- 精选：`featured/`的4份TSX为上游真实入口，4个轻HTML共享production IIFE与本地CSS/字体。图库读取一次共享资源，再向不授予same-origin的sandbox iframe填充srcdoc，避免不透明来源资源策略造成空白。不开放网络或表单提交。
- `featured/featured-source.zip`为4件共用下载包，包含107个构建文件、102个上游原件、真实依赖锁文件、运行预览与依赖许可。无node_modules。解压后在build中安装锁定依赖、运行Vite配置可重建；已用独立解压目录与锁定安装依赖重建验证。
- Magic UI卡片文案和轨道文字符号是演示适配；原组件运动逻辑和keyframes保留，不假称为上游完整页面。

[全部来源及字体许可](LICENSES.md)。图片与字体均不依赖外部CDN。规划文件中候选站不计入实际素材数。
