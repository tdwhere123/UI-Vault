# NES.css 原消息气泡

Existing ID `nescss:pixel-message-balloons`, one family, six original dark/direction combinations are not separate entries. Official nostalgic-css/NES.css at `b1cc9944aae3274461c747d7ad1cab31df45e78c`, full MIT copyright B.C.Rikko retained.

The complete original Storybook balloon template is retained after replacing only its import/export wrapper. It still emits the original Hello NES.css markup and nes-balloon/from-left/from-right/is-dark classes. Native checkbox/select stand in for Storybook boolean/select knobs; a tiny explicitly original host class-list helper replaces classnames for exactly the template's string/object inputs. No React, Storybook, network or model runtime. Only original transitive balloon SCSS is compiled: palette, variables, rounded-corners mixin and full balloons.scss. No unrelated icon/Mario collection, Bootstrap reboot or bitmap cursor is shipped. This is the original component showcase, not the entire NES.css documentation site.

The original rounded border uses its literal readable SVG path data URI in the upstream CSS. It is original text vector code, not a screenshot or encoded binary. Original geometry, tails, shadows, color values and all six states are retained. The surrounding labeled controls, page spacing and dark sample backdrop are an adapter host; Press Start 2P is not fetched/distributed, system monospace fallback is explicit. No font-face, cursor bitmap or external media. Sass is build-only (local 1.x compiler, version recorded), not shipped JS. Runtime is the original template plus small local controls/lifecycle adapter; root MIT covers the source graphic.

Actual550 composePreview: all six states render original text/classes, hidden retains the static state (no timer/animation), final exit removes owned change/pagehide/dispose handlers and disables controls; retained old events cannot change the output. Static CSS output still remains readable after exit. No native browser/pixel claim. There is no sending, message history or fake backend. Original sources/adapter are embedded in SOURCE; additional unrelated upstream repository files remain local only.
