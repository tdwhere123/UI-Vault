# OpenMoji · Exodus selection (120 bases)
This is an expressly curated selection from OpenMoji 17.0.0, NOT the full 4495-icon library. It contains 120 selected independent base designs and 240 original SVG files (color and black variants), counted as ONE icon series, not 240 UIs. Selected themes: communication/emotions, documents/resources, tasks/time, collaboration/tools/navigation. Skin-tone, gender and brand variant families are excluded. Related symbols are chosen for separate uses, not a count of globally unique semantic concepts.
Original graphics and metadata are reproduced unchanged under CC BY-SA 4.0, with original authors/dates/groups/subgroups/tags retained. See ATTRIBUTION.md, the complete license and the two public ORIGINALS JSON documents. No master MIT claim covers the graphics or data.
This browsing shell is original project code, not the upstream OpenMoji app. No upstream helpers, index.js or test code (LGPL) is used. There are no JavaScript runtime dependencies. Existing original SVG IDs are preserved; every selected SVG was checked to contain no href, use, gradients, URL references, scripts, images or styles. Duplicate unreferenced layer IDs therefore do not cross-reference or recolor other SVGs; no adapter CSS selects them. Original fill/stroke/path data and defaults are untouched.
Originals color/black total 445828 bytes. Source fixed commit f9fc506a3f913be9897ab0181d611d4c910a4104 is independently resolved as the 17.0.0 release. All 240 SVG Git blob hashes match its exact color/svg and black/svg tree entries. The complete package metadata, LICENSE and README hashes also match the fixed commit. Individual public entries carry exact SHA-256 and original source paths.
Search annotation/tags/hexcode, filter original groups, page through 24 bases, select color/black detail and inspect readonly SVG source. Per-image original source/author and CC links are visible. Links are attribution navigation only and do not trigger automatic requests; sandbox may prevent opening a new tab.
No clipboard/download/storage/network calls. All 240 actual DOM SVG element/attribute trees and source strings are tested against originals, along with all five pages, group/search/reset/repeated variant changes and exit cleanup. Visual/browser rendering has not been verified, and no screenshot or cover is supplied.
Public originals are plain UTF-8 source documents. Other adaptation source/build/test evidence is delivered locally under source/; no unsupported public download service is implied.
