# Cult UI · apple-keyboard

Original Cult UI apple-keyboard component and complete default demo retained. Only import aliases are resolved locally; cn retains original extendTailwindMerge soft-shadow class groups, unrelated siteConfig/absoluteUrl removed. Original SVG path data, gradients, filters, clips, text and keycap content not redrawn. useId comes from original component. Original utility classes compiled with Tailwind3.4.17; host supplies light white-card/border theme and system-ui font, no font asset or CDN. Host mount/unmount/error/resource ownership added; hidden unloads static scene and restores on reveal, repeated visible idempotent. SVG reference IDs remain unique and resolve after repeated mounts. This is a static visual asset, not an interactive chart, running Agent workflow, or text-entry keyboard. Keyboard retains original decorative button focus/pressed CSS, no invented command handlers. Each original full scene is one existing ID; no color variants counted. Keyboard includes original21 imported Tabler icon components with complete MIT. Normal/reduced/earlymodule/earlySVG/recreation-failure tests use actual536 composePreview; every listener, RAF and timeout cleared. No native pixel acceptance is claimed. Reduced motion disables original keycap transitions in CSS; static SVGs have no continuing animation. No networking, storage, clipboard, backend, images, screenshots or binary packaging.
