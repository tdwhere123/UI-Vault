# Momentum · 动量倒计时

Original full countdown demo and Momentum Slider engine preserved: 1–60 selection, loop duplicates, scale/opacity and deceleration, start/tick/progress/stop. Host adds keyboard arrows/Home/End, pause while hidden preserving integer seconds; interrupted slide settles through original animateTarget to its current intended whole index (active drag uses nearest step) on visible/blur/reduced; reduced immediate original animation step, positive-size initialization and listener/RAF/interval ownership. Countdown is foreground local demonstration, not a reliable background reminder. Google Roboto Mono request omitted; original monospace fallback retained. Geometry/clock stubs test real original callbacks, not native wall-clock or pixel rendering.

Source: https://github.com/lmgonzalves/momentum-slider/tree/b7b8a22ee759532b4fdc36340d49ac003a4fed61

No network, backend, clipboard, binary assets, worker, or new CSP permissions. Original engine plus documented host adaptations, not a replacement reimplementation. Browser pixel QA not run. atlas:dispose/pagehide permanently cleans the preview. See SOURCE-EVIDENCE.json and NOTICES.txt for fixed provenance and full licenses.
