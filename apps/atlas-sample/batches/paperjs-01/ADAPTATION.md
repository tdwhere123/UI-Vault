# Paper.js · Boolean material

Fixed source: https://github.com/paperjs/paper.js/tree/c1d88390d2c86901db152827fe778c3e39cfb073
Official npm artifact: paper@0.12.18, dist/paper-core.js. This prebuilt core is unchanged, rather than the repository dist development loader that fetches source dynamically. PaperScript and Acorn are not included; no eval or compiler is needed.

One boolean-geometry family: Join/unite, Overlap/intersect, Cut out/subtract. The official BooleanOperattions example's rectangle/ring primitive construction and original Paper.js boolean path engine are retained. Ring remains an actual subtraction of two circles, not a raster mask or mocked screenshot. Both operands can be swapped. Adaptation supplies local HTML controls, mauve/cream canvas theme, dotted original-shape outlines, actual result contour area readout, manual pointer drag and keyboard movement. Original PaperScript operator sugar is expressed as ordinary Point methods; no dynamic script translation. Dimensions are tuned for embedded detail view.

The original example's timer/autonomous orbit are deliberately removed: operation and position change only by user input. Exclude/divide are omitted after tests found signed compound-path area unsuitable for the intended area readout; they are not claimed complete. Three retained operations pass union/intersection/subtraction area identities within cubic-circle approximation tolerance. Readout is an approximate vector contour area, not a fabrication or metrology guarantee.

Lifecycle: view autoUpdate=false, view paused; explicit view.update on user input. No continual animation or polling. Engine may queue an initial single update; it drains and stays idle. Hidden page ends active drag. Pagehide clears host handlers, pauses/removes PaperScope/project/view, with zero steady RAF afterward. Paper.js retains inert library-wide document dispatch listeners for its module lifetime; the normal lazy-loaded iframe teardown removes those too. No network, storage, real tasks or external assets.

Verification: JS parse and actual delivered runtime in JSDOM, browser user agent provided to avoid the engine's Node branch. Canvas context is mocked, not visually inspected. Real path engine computes fixture areas (subtract 53012.827; intersect 14587.173; unite 76895.617). Tests cover boolean identities, drag changing real intersection area and position, release-stop, arrow key, reset, operand swap, hidden-stop, scope cleanup, no continuing RAF/network. Real canvas pixels, hit testing, touch capture and aesthetics remain UNVERIFIED. Explicit HTML head supports host CSP injection. Six-file delivery is all UTF-8 text.
