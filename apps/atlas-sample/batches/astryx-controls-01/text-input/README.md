# Meta AstryX · text-input

Original Meta AstryX visual components used through their documented API with explicitly host-authored minimal local controlled fixtures. Not an official complete application or backend. Each independent functional family has one entry; states/parts are not separate entries. NumberInput quantity0–10, Radio local mode, Selector local status, Slider intensity0–100, Switch boolean preference, TextInput/TextArea plain local sample text, TimeInput local time, Pagination95 sample items, ProgressBar manual simulated progress. Original core components/geometry/styles unchanged, only host values/handlers/output and labels supplied. Source documentation fixed repository0.7.12 with installedcore/theme/build0.7.11 compatibility runtime explicitly disclosed. Per-entry independent IIFE via shared StyleX/theme/LayerProvider and system font fallback. No network, persistent storage, real accounts, service submission, clipboard or media. Hidden unmount resets fixture state and visible remounts; exit/error cleans owned resources. Actual550compose and loader/cache/release plus each original key state behavior tested under JSDOM, shared early/late/reduced test rather than duplicate matrices. Native pointer drag, locale IME, focus geometry and CSS pixels are not verified. Exact StyleX CSS parser warning recorded separately. Root MIT and all actual emitted dependency full licenses retained; prior official core/StyleX missing-file supplements clearly labelled.
