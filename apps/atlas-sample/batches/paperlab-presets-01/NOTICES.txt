    https://creativecommons.org/publicdomain/zero/1.0/

not appear in the published tarball — the library takes a `figure.model`
URL and the apps host the file. Anyone consuming the library brings their
own asset and their own licence obligations.



────────────────────────────────────────────────────────────────────────
Hand and face tracking (the /hands page)
────────────────────────────────────────────────────────────────────────

`/hands` drives paper with a camera using MediaPipe Tasks:

    @mediapipe/tasks-vision — Copyright Google LLC
    Apache License 2.0
    https://github.com/google-ai-edge/mediapipe

The two halves are treated differently, on purpose.

**The wasm runtime IS served from this site.** It is that npm package's own,
copied out of `node_modules` by `pnpm hands:setup` and built into the page.
Apache-2.0 covers it, so hosting it here is unambiguous — and it has to be
hosted here, because it is executable code running in a page that holds a
camera stream, and nothing else in this project fetches that from a third
party at runtime.

**The model weights are NOT.** `hand_landmarker.task` and
`face_landmarker.task` are loaded from storage.googleapis.com at runtime,
by the visitor's browser, only after they press start. They are not
committed, not vendored, and not in any build output.

That is deliberate rather than lazy. Google publishes no licence for the
model files anywhere that could be found — not on the task's documentation
page, not on the models page, and the model card those pages link to
returns 404. The code is Apache-2.0; the weights are covered by nothing
anyone can point at. Serving them from this origin would be redistribution
under terms that cannot be read, so the page links to Google's own copy
instead, and says so in the panel where a visitor can see it.

If those terms ever become clear, self-hosting is a two-line change and a
better page — one less third-party request, and it would work offline.
Until then this is the honest arrangement.

No video, and no measurement taken from it, ever leaves the device. The
page carries a Content-Security-Policy that permits the model host and
nothing else; MediaPipe's own usage logging (odml.pa.googleapis.com) is
blocked by it, and `pnpm test:hands` fails if either that endpoint or any
other stranger is contacted.
