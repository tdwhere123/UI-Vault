# Runway loader: local motion study
Source: https://github.com/aicanvas-me/aicanvas/tree/8164f1e423e4e654dd0828a941ba5cdda69f08fe/components-workspace/runway-loader
Original free component MIT, 2026 AI Canvas. Root README explicitly designates components-workspace the free MIT library. No premium files or root scripts used.
Original SVG plane, runway material, timed easing, taxi/takeoff/reset phase logic, and light/dark colors retained. Added explicit play/stop host, default stopped, visibility unmount/restart, and full clearing of original nested reset timeouts on unmount. Local clock simulation only: no upload, travel booking, task engine, or actual background progress. Themes are one entry, not separate counts. No remote images/font/network calls. Dependency notices collected from actual esbuild inputs and Tailwind CSS.
Testing: opaque-origin JSDOM semantic phase/cleanup tests with manually advanced RAF; dynamic eval/Function/network blocked. No real browser was available: actual plane motion pixels, touch/mobile, layout and reduced-motion transitions are NOT visually accepted. User must click Play to run, even when reduced motion is not requested. Public source files here are actual adapted files, not an uploaded upstream archive.
