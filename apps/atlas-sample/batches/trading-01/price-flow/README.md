# NumberFlow Trading

Original UILayout NumberFlowTrading and PriceWithDiff retained: three fixed price/diff pairs, original Shuffle SVG, USD/percentage formatting, red/emerald pills, Motion arrow rotation and NumberFlow digit implementation. Local fixtures only: not live financial data, advice, accounts or transactions. Original import cn is resolved to clsx/tailwind-merge; original state initializer/onIndex reporting minimally adapted so hidden unmount can restore index. Host adds a dark canvas and fixture label, preserves original utility classes via Tailwind compilation. Animation ownership removes finish/cancel records without replacing library onfinish; a controlled EventTarget WAAPI probe covers 1000 completed/canceled objects and pending hide/exit cancellation, not native rendering. Repeated visible events keep the existing root. Hidden unmount cancels WAAPI, pauses owned RAF; visible remount restores index; reduced uses original library preference and MotionConfig. Isolated iframe listener/timeout/RAF/animation ownership is cleaned on pagehide/atlas:dispose/failure, including partial initialization. All source graphics are original text SVG; no images, fonts, network, clipboard or backend. Actual original component state and NumberFlow data/digit DOM execute under unsupported-animation fallback in JSDOM; no claim of native WAAPI or pixel acceptance. Native animated layout remains unverified. Source inline Shuffle icon has no separate attribution in the original file and is retained under upstream MIT; Lucide arrow includes ISC and Feather MIT attribution.
