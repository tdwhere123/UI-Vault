# AI Canvas · Curious AI
Original AI Canvas Curious AI visual component, fixed 8164f1e423e4e654dd0828a941ba5cdda69f08fe, components-workspace/curious-ai/index.tsx. This is a local animated character, not an AI model, assistant service, microphone or backend.
Production uses real Three.WebGLRenderer, original geometry/material, byte-identical original VERT/FRAG shader strings and original DOM eye overlays. Original cursor tracking, near-orb squint, distant look, idle gaze sequence and blinking remain. No fake shader or replacement orb is used.
Narrow adaptations: explicit WebGL unsupported notice with no successful eye-only orb; guarded partial initialization, per-frame rendering, shader-error callback, context-loss and resize failure disposal; retain/cancel 500ms touch grace on repeated touch/down/cancel/leave and unmount; pagehide root cleanup. React shared document selectionchange and Motion shared window resize callbacks are recorded only within this isolated preview and explicitly removed at exit, then original listener methods restored. No arbitrary existing listener is removed. Hidden documents unmount the component, clearing idle/blink/grace work; visible documents remount a reset idle character. A preview-local RAF owner is initialized before Motion so hidden frames are canceled without abandoning its shared scheduler state; pending scheduler callbacks resume only upon visibility, while disposed renderer callbacks are no-ops. Pagehide permanently clears this queue and restores original RAF methods.
The original scoped-theme palette remains. Tailwind utility layout is reproduced as local CSS without a remote stylesheet. No external images/fonts/requests, storage, workers or eval. No screenshot or cover.
Reduced-motion is NOT a complete pause: original shader uReduce freezes noise time and initial reduced preference prevents automatic blink scheduling. Gaze smoothing, rotation and pointer-triggered eye state can remain. Dynamic preference changes update shader uReduce; the original blink scheduler checks preference at mount only. This boundary is retained and tested rather than claiming a globally motionless mode.
Tests:
- Production real renderer with unavailable WebGL: explicit unsupported text, no canvas/no successful eyes.
- Test-only renderer exercises real Three scene, IcosahedronGeometry, ShaderMaterial, uniform and pointer/idle/eye state. No GPU output is claimed.

- Repeated hidden/visible cycles with pending touch grace stop background work and reset on remount; real elapsed 500ms grace returns eyes to 0.85.
- Initialization render failure after resources exist disposes them; early pagehide before mount leaves no active lifecycle work.
- After exit, zero component/global tracked listeners, timers, RAF, observers and network/eval/Worker calls. Geometry/material/renderer disposal and context loss are checked in the renderer test.
The shader string comparison is byte-exact to upstream. Mock renderer tests do NOT validate shader compilation, actual GPU pixels, surface appearance, browser performance or physical pointer geometry. browserVisualQA is not-run.
