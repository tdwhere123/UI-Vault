Poline Picker

Original interactive example · OKLch/Lch use the original HSL-based approximation, not colorimetric conversion.

Experience the magic of "poline" for yourself, dear color explorer. Drag existing anchor points to adjust colors. Drag the outer ring of an anchor point to adjust its saturation. Press P to add a new point at cursor position, and press ⌫ to remove the last selected anchor point. Try using the ← and → keys to change the hue of all colors. Hold Shift while adjusting saturation for finer control.
