# eldora:novatrix-background

Original complete official Demo and its component, not a new visual skin. Original GLSL retained.

System-font/light CSS tokens and original Tailwind utility compilation; no external fonts or image assets.

Shared lifecycle boundary: WebGL compile/link checks, allocation tracking, context-loss failure, partial-init cleanup, visibility unmount/remount, stale RAF/timer guards, missing-root fallback.

Zero-sized outer preview waits or disposes until sized. No fake fallback effect.

Original fixtures are aesthetic UI; no actual AI service or account operation.

Original resize ignores zero-size component. Official defaults color[1,1,1], amplitude0.1, speed1, mouseReactfalse retained. Optional original mouseReact prop is not falsely claimed enabled.

Reduced motion draws one original OGL frame and schedules no continuous RAF. OGL allocation leftovers released in addition to original cleanup.

Validation uses actual clean ui-vault-550 composePreview and default CSP, production JS and actual OGL/Paper renderer code against recorded WebGL methods. Normal original draw/shader submissions, static reduced mode, hidden teardown/remount, zero size, canceled old RAF, missing root, early exit (including pending Paper async creation), initial hidden, unsupported GL, shader failure, late render failure and context loss checked. GL allocations/deletions, observers, final RAF and full EventTarget listener ledger balance verified. GLSL offline parser checks syntax only. **Native GPU compilation, native hit testing and pixels remain unverified.** No screenshots, native browser attempts, alternative simulated visuals, backend or remote asset calls. No claim that command counters are a rendered-picture acceptance test.

Original labels, examples and inline brand marks are demonstration content, not endorsements. Tests' dimensions and WebGL status/functions are deterministic substitutes. CSS uses system font and local basic theme tokens rather than a remotely fetched site theme; responsive classes and original layout remain. Paper renders original complete demo's multiple desktop/mobile visuals; CSS-hidden variants may still allocate a context like upstream, bounded and all disposed.

Local build: npm ci --ignore-scripts; ./node_modules/.bin/tailwindcss -i input.css -o compiled.css --minify; node build.mjs novatrix; node test.cjs normal novatrix. Other focused modes: reduced, missingroot, earlyexit, initialhidden, unsupported, shaderfail, latefail, contextlost. Preferred-source workspace is private implementation evidence; public seven files are standalone built text assets with complete license notices, not a promise of a public build workspace.
