# Motion Core · lava-lamp

One existing `motioncore:lava-lamp` family, fixed kaltwrk/motion-core@74ad6e66d50cc9b1849a505fcd1b352704920745. Original complete Demo → component → Scene is bundled, not a CSS substitute. Original inline GLSL literals, OGL geometry, default props and render equations preserved. No texture/media/network/camera/GSAP. Original MIT and actual emitted dependency licenses supplied; OGL1.0.11 full Unlicense is in its original README included in NOTICES. Svelte5.39.6, clsx2.1.1 and tailwind-merge3.4.0 are pinned compatible versions, not claimed exact upstream lock.

Original Demo exposes parameters as props but has no visible parameter control panel. Added host Pause/Resume(restart)/Restart buttons are lifecycle controls, not misrepresented upstream UI. Utility CSS implements original position/size wrapper classes; original shader supplies the visual effect. DPR capped2. Hidden unmount releases GPU resources and return resets scene. Reduced motion allows one original frame; paused last frame remains until resume restarts. Zero-size root waits for resize. Unsupported, shader error, render error or context loss shows honest error, no fallback simulated picture; Restart explicitly retries.

Shared guard records actual WebGL allocations even during partial initialization, deletes buffers/shaders/programs/textures/framebuffers/renderbuffers/VAO on cleanup, removes context listeners, stops owned RAF/timeouts and requests WEBGL_lose_context when available. Shader compile/link failures and incomplete offscreen framebuffers stop rather than log-and-loop. Running zero-size roots release context and resume when resized. Original component cleanup is retained before remainder cleanup. All scripts/CSS local text, default atlas CSP unchanged.

Tests use actual548 compose and original OGL with stubbed WebGL command/status functions, not a mocked replacement renderer. Verified original GLSL submission, draw commands, reduced/static, hidden restart, stale RAF rejection, paused exit, unsupported/contextlost/shaderfail/late render failure and allocation/deletion balance. **No real GPU shader compilation, pixels, native touch or screenshot QA**. Runtime may still encounter device-specific shader support/performance issues; those fail visibly. All16 original shader literals across this batch also passed offline @shaderfrog/glsl-parser7.0.1 syntax parsing (build-only tool, not bundled); this is not native driver validation. Source shader hashes are static evidence, not GPU acceptance. Fluid's original pointer move was exercised: two additional splat passes appear on a movement frame; this is command-flow evidence, not rendered fluid pixels.

Local commands: node build.mjs lava-lamp; node test.cjs normal lava-lamp; modes reduced/unsupported/shaderfail/latefail/contextlost. Build is independent; do not run while another slug is building because selected Demo.svelte is shared. Public seven files are built text assets, not a promise that the private build workspace is public.
