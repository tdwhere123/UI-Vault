# TinySynth · 原版音色设计控制台

原完整 soundedit 音色工作区：128 个原音色、质量切换、四振荡器与 AHDSR 参数、实时 patch 读出、八度/通道/延音与原键盘试音。点击“启用声音控制台”后才创建本地 Web Audio；请先降低设备音量。“全部静音”、隐藏及退出会释放音符。

范围明确：这不是完整 MIDI 播放器。未打包原 ws.mid（曲目授权未单独闭合），不预载/导入文件、不访问 MIDI 硬件、不联网、不保存。默认字体使用原声明的系统回退，不下载 Google 字体。原控件 SVG 皮肤从源码生成，百分号编码为实际图形，不是二进制封装或封面。

引擎与控件分别为 Apache-2.0，完整原条文及 Controls 多位作者署名在 LICENSE.txt；精确修订、Git blob 与 SHA256 在 SOURCE.json。原递增振荡器存在多增一行问题及控件 const delta 重新赋值已作定点修正；原合成/包络/噪声生成逻辑未重写。动态表达式转换不是本 demo 所需功能，已从使用路径移除。

实际564 compose、原音色选择/参数编辑/声部调度、重复操作、隐藏、退出和提前关闭、无音频能力、部分音频分配失败已验证。测试中的 AudioContext 节点和 Canvas2D 是边界桩，真实设备声音质量、触控/键盘几何与像素未验，不将模拟节点称为音频输出验收。

公开仅本目录七个文本文件；完整原源码、修改源码、构建工具与测试在本地工作目录，无虚构源码 ZIP。不能在此版本导入任意 MIDI 或连接外部服务。
