# Cuicui Dynamic Settings

Original source: damien-schneider/cuicui @ `c7db00f2e98753c277f1aec6e316520038f4e0a0`, MIT. Inspiration attribution preserved from original component.ts: UI Labs, https://www.uilabs.dev/. Runtime distribution MIT and ISC (Lucide includes Feather-derived MIT portions). Fixed source SHA is not a claim that the independently pinned dependency graph recreates the original upstream lockfile; all actual versions and notices are enumerated in SOURCE.json.

## Original UI and honest scope
Retains original rounded dark expanding settings panel, 3 categories, 6 aspect-ratio selections, prompt textarea, local category/selection state, plus/close icon, Motion springs/blur and highlight layout. Dimensions was upstream TODO and remains without sliders. Host says so naturally. Apply still calls Sonner and closes the panel, but misleading success words changed to “本地演示回执 / 仅演示，未应用或保存设置”. No backend, save, model request, upload, real application, credential, file or network operation. Original category/ratio/prompt transient state and reset semantics preserved.

Minimal adaptation: aliases resolve original cn; controls gain accessible labels/aria-pressed; Apply type is button; useReducedMotion supplies zero-duration transition branch while normal transitions are original; MotionConfig reducedMotion=user. One fixed Sonner toast id bounds its store and updates the same receipt instead of accumulating 100 notifications. No fake new persistent behavior. No remote fonts/media exist in this original component, and none are introduced; host uses system fonts. Tailwind generates original utility classes; Sonner includes its own package CSS in JS.

## Lifecycle
Isolated iframe host copied and extended, not a modification of any frozen delivery. Exact newly added EventTarget handlers, legacy matchMedia callbacks, active observers and timeout/interval/rAF are owned and cleaned on final exit after React unmount. Pre-existing external selectionchange remains untouched. Hidden dismisses the demo receipt, unmounts contents and pauses pending callbacks; visible starts closed, no stale toast. Scoped MutationObserver releases exact registered listeners on actually detached DOM nodes after mutations, preventing old textarea invalid handlers from accumulating through repeated prompt mounts. Still-connected handlers and pre-existing external handlers are not removed. No public testing globals.
