# Cult UI direct batch 03

Five existing candidate families: Tabs Illustration Vercel, Circuit Board, Analytics Chart, Toolbar Expandable, Expandable Screen. All five original component implementation files are preserved byte-for-byte. Adaptations affect demonstration wrappers only: Tabs demo min-width restriction relaxed for smaller containers; Next Image shimmed to plain img; missing avatar placeholder replaced with local original SVG geometry. System fonts used. Original and adapted files supplied separately.

A capturing host handler cancels all anchor navigation and form submissions, displaying a local status notice. There are no APIs, true deploy actions, waitlist registration, or financial-account data. Analytics figures are upstream synthetic demo datasets. Example form input is never sent or persisted.

Build and non-visual checks passed: JS syntax, Tailwind CSS generation, no remote CSS imports/assets, five JSDOM React mounts with zero errors; Image tab changes active styling; circuit external link click prevented; Analytics Signups tab switches dataset heading; Toolbar expands and resets state; Screen CTA opens its form, submit is canceled, close restores body scroll.

Limits: browser rendering/animation has NOT been checked. JSDOM does not reliably complete Motion exit animations, so full visual disposal of the closing Screen overlay is not certified. Keyboard/focus accessibility, dropdown interaction, viewport layouts, complete repeated-open lifecycle and visual quality remain unverified. Screen original trigger is a clickable div, not a keyboard-native button; no accessibility pass claimed.
