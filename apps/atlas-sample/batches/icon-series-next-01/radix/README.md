# Radix Icons

All 332 SVGs under packages/radix-icons/icons/ at fixed revision. All files in specified official SVG source directory, not font/React packages. One family, not one UI per glyph; semantics overlap existing series. Original SVG bytes and geometry retained. Shared original UI-Vault/Maki/Bytesize browsing shell adapted once for these3collections; not an upstream application. Search/pagination30+detail/size/color local only, no clipboard/download/API. Color adjusts currentColor rendering, not hardcoded original fills. Internal mask/clip IDs scoped on cloned display nodes to avoid collisions; published ORIGINALS retains exact bytes. Ordinary UTF8 JSON data split at whole records below700KiB; no base64/binary packaging. Complete original rootlicense included; MonoREADME separately confirms SVG use despite font wording. Brand marks belong to owners; MIT not trademark permission or endorsement; known brand names annotated, classification not a comprehensive trademark determination. Hidden defers paint,exit aborts listeners/clears template cache. No native visual QA; DOM/XML/source tests only.
