# Local task timeline adaptation
Fixed source: https://github.com/visjs/vis-timeline/tree/353464dd6438ea31f4a6e416ab7e07d8cc0f519d
Original Timeline engine is copied from this fixed lib/ source and bundled unchanged, NOT substituted with an npm runtime version. MIT alternative chosen; full license and runtime dependency notices retained. Reference examples: examples/timeline/editing/editingItems.html and examples/timeline/groups/groupsEditable.html.

Original local host supplies fictional November 2026 tasks and lanes, an edit form, hide/restore controls, a visible stored-data receipt and stop/restart. Soft rounded theme is a local visual adaptation. Actual engine DataSet handles addition/deletion, title/date/group changes and original native drag edits. No calendar account, reminders, network, background job or persistence. Time ranges are local fixture dates. Current-time ticker and engine autoResize polling are disabled; ResizeObserver handles visible layout and is disconnected on pagehide. Stop calls Timeline.destroy; pagehide also destroys. State remains in memory for local restart only.

Verification: production IIFE, JS parse; real-runtime opaque-origin JSDOM with geometry/ResizeObserver stubs: mount, add, edit, actual stored group/date changes, invalid-range rejection, hide/restore lane, delete, destroy/restart and pagehide cleanup. No console errors or network fetches. Actual pointer timeline dragging/cross-lane hit geometry, range-resize gestures, group pointer reorder, visual layout and touch accessibility remain unverified. Do not claim DOM tests certify those interactions or pixels. Load only inside an opened lazy detail, not every catalog card.
