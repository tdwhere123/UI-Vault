# Netron original local structure explorer

Fixed upstream 37377fd1480501404e58ff579cf4c3f3a867572c; official .netron JSON reader, original complete graph/inspection workspace, explicitly authored local fixture.

- Original Netron View, sidebar, graph rendering/search/zoom and original ModelFactoryService + official message.ModelFactory .netron JSON reader. Not the original network-enabled browser host, not all Netron file formats. No inference, training, credentials, model download or real trained weights.
- The four-operator classifier JSON is authored specifically for this local preview, NOT an official sample, user model or evidence of real model performance. Original reader builds graph operators, connections and tensor shape/type metadata. Synthetic Dense/ReLU/Dense/Softmax nodes are illustrative.
- The small JSON editing dialog and two helper controls are authored adapters. Bound to one graph, 1–32 operators, <=128 values/connections, <=70000 characters, finite scalar attributes and bounded tensor dimensions. Rejects active markup, external URLs, prototype keys and binary initializer payloads before original parsing. Not a generic JSON/ONNX/PyTorch importer.
- Original serial Dagre branch runs locally without Worker. Only grapher Node-only fs diagnostic output was removed. Two disposed guards were added after asynchronous View.start initialization boundaries; normal reader/layout/inspection algorithms are unchanged. Original source patches/hashes are provided.
- Original full inline SVG toolbar graphics, HTML structure, system fonts and grapher CSS are retained. Original browser host with telemetry/cookies/remote file opening is not emitted. Host storage is an in-memory Map. External opening, sharing, saving, image export and arbitrary file access are unavailable.
- No emitted npm runtime dependencies. Fourteen fixed upstream source modules plus authored host/fixture and disposal wrapper. Netron root MIT is complete. Dagre source points to dagrejs/dagre and graphlib: full official historical MIT notices are additionally preserved as conservative upstream attribution; this is not a claim that the adapted Netron file is byte-identical to those npm releases.
- Actual569 adapter/createPreviewLoader/default-cache measured 2032094 UTF16 bytes for HTML/CSS/two scripts, below unchanged 8388608-byte budget; remount cache reuse, failure all-or-nothing and retry passed. Every JS chunk is a natural complete-statement file below 700 KiB, no encoded payload/eval/Function/runtime compilation.
- JSDOM functional tests use controlled SVG BBox/matrix fixtures, not native pixel/layout/drag or visual fidelity QA. Hidden pages blur inputs and retain model; finite work may settle. Final exit clears listeners/timers/intervals/RAF and invalidates old controls/callbacks. Early exit and missing root covered.
