# Original nested query builder

One complete upstream React Awesome Query Builder Query / Builder / BasicConfig UI at commit `446689d523d699dbf8f536dfcfcb076ea58725dc` (repository package version 6.7.0-alpha.0), MIT copyright 2016 Sebastian Siemssen. This is the original lightweight/default UI and stylesheet, not a reimplementation or AntD/MUI skin. Default 5px corners and amber nested group styling are intentionally retained. This preserves a functionally distinct original UI; no claim of luxury visual design.

The surrounding explanation, four local document-field definitions, two seed conditions, Reset button and JSON output are adaptation glue based on the upstream README Query/Builder example. No database, backend, document execution, imported expression execution, SQL evaluation, model, persistence, external images/fonts or network. Only original Utils.getTree produces the read-only JSON. Local strings remain React text. Original built-in field/operator/value normalization remains enabled; number field is configured 0–10. This is not a promise that arbitrary incomplete rules are executable valid database statements.

Original AND/OR/NOT, nested groups, add/delete rules, original locking controls and typed text/number/select/boolean widgets are retained. One minimal vendor change: SortableContainer.componentWillUnmount removes mousemove/mouseup handlers from its eventTarget, removes dragging body/tree CSS classes and clears cached elements. Original code lacked mid-drag teardown. No original query algorithms rewritten. Original source is preserved separately under local source/upstream-originals; adapted vendor under source/src/vendor.

Tests exercise original DOM controls (not callbacks): nested group/rule addition, OR/NOT, text→boolean operator/value normalization, select→number old value clearing, deletion, reset and repeated changes. A real mousedown on the original drag handle attaches two document.body handlers; pagehide unmount removes both and the dragging class. DOM geometry is not mocked, but JSDOM has no actual layout, so actual visual reorder/real pointer geometry is NOT accepted. Timers/RAF and drag listeners reach zero. Saved harness evaluator starts the bundle, then runtime eval/Function/fetch/XHR/Worker/WebSocket/storage are trapped: zero calls. No visual/browser screenshot or native keyboard acceptance claimed.

Runtime includes upstream core's optional import/export dependencies (including spel2js), but the host never calls execution/import evaluators. Lodash contains dormant Function global-detection/template code: browser self/global detection avoids it and all tested paths run with Function throwing. This is a behavioral CSP test, not a false claim of no forbidden strings in bundled vendor source. No sandbox permissions expanded. Source/dependency notices preserved for all actual 21 bundled packages, including spel2js Apache-2.0 banner+NOTICE and full standard Apache license, chroma-js BSD3+Apache2 and all copyright text. Standard Apache license retrieved from https://www.apache.org/licenses/LICENSE-2.0.txt.
