# Ionicons 8.1.0: complete original series
1357 original published SVG assets: 421 filled, 421 outline, 421 sharp and 94 brand marks. This is one icon-series collection, not 1357 independent UI designs. The original offline browser shell is ours, not an upstream Ionicons application.
The exact asset source is official npm ionicons@8.1.0, verified against its SHA-512 tarball integrity. Every public ORIGINALS-*.json entry preserves the complete UTF-8 SVG source and its SHA-256. Names, paths, fill, stroke, transforms and metadata remain unchanged. Browser currentColor inheritance is used; no paths are flattened/recolored or reoptimized.
Source attribution caveat: official v8.1.0 tag resolves to d1e2c48641fd5f4910ee42a144dc1c84b1a9a4ee, whose package.json says 8.0.13. Its 1357 src/svg names match package dist/svg names, but the published files are optimized and are NOT byte-identical. npm gitHead did not resolve independently. PROVENANCE.json states the exact npm asset source; the tag is supplementary lineage, not falsely asserted identical source.
Search full names, filter styles, browse 24 at a time, select and enlarge, switch available same-name styles, and inspect readonly original SVG. Brand entries have only their standalone style. No clipboard action, download, storage, network, external resources, Stencil runtime or workers.
All glyphs pass a strict tag/attribute/resource allowlist. DOM tests cover paging, search, repeated variant selection, reset, hostile search text and exit cleanup. All 1357 public SVG texts are compared to package originals. Browser visual appearance remains unverified.
