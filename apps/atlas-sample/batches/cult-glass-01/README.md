Changes: external default images replaced by original local SVG artwork; URL field and Load URL button disabled, loading function no-op. All imagery is labelled original local studies. Original presets and parameter state logic preserved. A WebGL2 capability probe releases its probe context when the extension is available, then renders the actual shader. Validation: JS parses, build succeeds. JSDOM tests cover unsupported fallback and the real Paper engine receiving mocked WebGL methods. Sliders change real engine uniforms, reset restores defaults, a preset changes uniforms, image switching disposes the previous mount, and unmount removes shader canvases, deletes GL programs, disconnects observers and clears tracked RAF/timeouts/intervals. Paper's one global static stylesheet may remain, which is not a live mount or animation resource. Mock tests DO NOT verify GPU shader compilation, actual pixels, canvas appearance or performance. Browser visual review remains pending. No network API calls occur in tests; mock image loading accepts data:image only. Runtime contains no eval/new Function/worker/importScripts entrypoints.
