Original mask-image/background-image plumbing becomes inline SVG; placement is an adaptation and awaits pixel verification. Original encoded SVG grain is replaced with an actual inline SVG using the same turbulence/color-matrix recipe, without data URLs or binary packaging.

Default ambient motion is paused. Static light-layer visibility is set so the paused scene is lit, rather than waiting at zero opacity on intro frames. Play allows original bump formula and CSS drift; Pause stops interval and pauses CSS animations. Hidden documents cancel bump interval and pause CSS animations; visible resumes only when playing. System reduced-motion blocks ambient interval and retains original reduced-motion CSS. Stop & clear unmounts listeners/interval; pagehide unmounts root. The media-query helper is replaced by Motion's equivalent reduced-motion hook. Root application, premium code, install hooks and lifecycle scripts are not used.
