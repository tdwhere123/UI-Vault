# impress.js · Spatial brief

Fixed source: https://github.com/impress/impress.js/tree/b44b9694b41fd2c076c3d1ad7a0c3e0cea9eb262
One spatial-navigation family, not a component per chapter. It differs from an ordinary deck by placing chapters in one persistent rotated/scaled/3D coordinate space, with an overview and arbitrary chapter entry.

Retains original impress.js CSS3D engine and gc/util/rotation libraries. Uses original demo positions/scales/rotations for title, its, big, tiny, ing, imagination and overview, plus corresponding original typography/transform rules. Local six-part sample prose about reading/handoff replaces original promotional text; it is NOT a user report. Local controls expose original goto/next/prev and overview, direct section click, dropdown and keyboard navigation. System serif/sans fonts replace optional remote fonts. Source demo's embedded base64 logo and ordinary slide styles are omitted, with no binary or encoded image asset. No remote links/plugins/automatic fullscreen/audio/network calls.

Lifetime: only finite transition timers, no autoplay/polling/RAF loop. Original tear() is patched to clear its pending stepEnterTimeout before GC teardown. Stop tears down the engine and hides the restored scene; Restart recreates it. Original internal hash bookkeeping is iframe-local and may reopen the last local chapter on restart. Pagehide removes custom handlers and tears down engine. Reduced-motion sets transition duration zero and disables CSS word transitions. Window resize refreshes the current original engine position. The source may call scrollTo(0,0) to suppress native hash scrolling; this is iframe-local.

Tests insert actual delivered runtime into opaque-origin JSDOM. Browser scrollTo is stubbed because JSDOM lacks it. Tests validate initial chapter, original negative-z transform, next/back, overview root transform change, arbitrary goto, dropdown selection, arrow/Escape/Enter keys, resize refresh, Stop teardown, Restart reentry and pagehide teardown including pending transition completion wait. Tested both normal and reduced motion. No script errors/fetch. DOM/CSS transform strings and class state are tested, NOT CSS3D projection, pixels, transition aesthetics, physical keyboard focus ergonomics or true pointer hit geometry. Visual acceptance remains PENDING. Host has explicit head for CSP injection. All six delivery files are UTF-8.
