# Font Awesome Free 许可（按原文分项，不是一律 MIT）

本批预览与源码包内嵌的 Font Awesome Free 资源，许可以官方 `fonts/LICENSE-FONTAWESOME-FREE.txt` 原文为准：

- **图标**（SVG 与 JS 形式）：Creative Commons Attribution 4.0 International（CC BY 4.0）
- **字体文件**（web/desktop fonts，包括本批保存的 woff2）：SIL Open Font License 1.1（SIL OFL 1.1）
- **其余非字体、非图标代码**：MIT
- 需要按 MIT、SIL OFL 与 CC BY 保留署名；品牌图标仅为对应商标持有者的标识，不得挪作他用。
