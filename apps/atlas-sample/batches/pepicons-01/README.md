# Pepicons · Exodus selection (113 bases)
113 selected bases, each in the original pencil, pop and print styles: 339 SVGs, one icon series. This is NOT the complete 1275-base collection. The selection emphasizes files, messages, input, collaboration and navigation, without number/alphabet sets or repeated circle/off status decorations. Related functions can share concepts with other libraries; this is not 339 independent UIs.
