# Solid Glass Agent workspace

Original MIT block by DeepLethe. A full three-column Agent workspace with local session, file, task, composer and decision-card interactions. Demo data and the fixed response are upstream example behavior, not a connected AI backend. No API key, server, or external data transmission is required. Do not confuse the sample session research output with real research.

Original import closure is preserved under original/. Runnable adapter is under runnable/. Only the mount, global stylesheet and standalone production build are added; block/component logic remains unchanged. Run `npm ci && npm run build` in runnable. No node_modules included.
