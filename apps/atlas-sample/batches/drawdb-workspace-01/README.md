# drawDB · original local relational-schema scene

- Original fixed Editor provider chain, Workspace, SidePanel, SVG Canvas/table/relationship components, ControlPanel local actions and Undo/Redo remain. Initial content is the original official template1 Blog database schema (5 tables,5 relationships), not invented remote data. This is a local visual relational-schema scene, not all hosted drawDB features.

- Persistent Dexie storage is replaced by an explicitly transient fixture repository. Autosave/storage and network sharing/Gist, file transfer, image/PDF/SQL/DBML import/export, clipboard, cloud and AI paths are unavailable. Original dirty-state save callback only returns to a visibly labelled transient/not-saved state; it does not pretend persistence. Hidden restoration resets the original fixture; close discards edits.

- Original table/field/relationship editing, new connector linking and history use original code. Original Rename form and title-setting flow are retained in a small local modal wrapper. SQL/DBML/Monaco, SQL-header and view-authoring controls are disabled; no replacement text field is passed off as Monaco. Dagre LR/TB and subject-area layout remain original; optional ELK backend is not included.

- Official Semi UI named exports are resolved to their official component modules rather than the omnibus barrel, retaining original used implementation/style rules while avoiding unrelated parsed widgets. React18.3.1 and fixed installed dependency versions are recorded. Source and root license do not stand in for actual dependency notices.

- Root and combined isolated application are AGPL-3.0. All applicable component MIT texts, author notices and compiled TailwindMIT are supplied. Full editable application/adapters, parsed dependency code/metadata/licenses, preferred official Semi gitHead TS/SCSS and React18.3.1 source additions, source-map original TS/JS, exact install manifest/lock and rebuild scripts accompany this scene as natural UTF8 files. No binary/source ZIP fiction. Source source-only packages are separately labelled.

- Original media/font imports are not redistributed as encoded binaries. PNG/JPEG compilation inputs are transparently empty markers for the empty loader; UI source retains its text/path provenance. Existing original inline SVG components and licensed Semi SVG icons remain. Font Awesome/Bootstrap font glyph placeholders are explicit system symbols; original font/icon pixel fidelity is not claimed.

- No CSP/sandbox/cache expansion. Three independently parsed natural runtime scripts each below700KiB. Top-level function promotion uses anonymous expressions so original outer self-rebinding semantics are retained. Any module exception closes owned resources and prevents later scripts from starting.

- Actual575 compose tests use the real production bundle: original5-table/5-FK fixture, Add table→Undo/Redo, synthetic original pointer-port linking creates6th relationship→Undo, original FK-name editing including HTML-like text→Undo, hidden/reset/retained old node and complete final EventTarget/timer/RAF/interval/observer cleanup. Early module failure cleanup and blocked network/storage/eval APIs tested. No test-only state exposure.

- Controlled JSDOM rectangle/SVG bbox/length/point and observer fixtures exercise behavior, not native geometry or visual accuracy. No native browser/screenshot, precise drag/touch ergonomics or exhaustive all-tool acceptance is claimed.

- Actual createPreviewLoader/cache all-or-nothing/retry/remount uses 3614146 UTF16bytes/5entries within unchanged8MiB. Fresh final source extraction, normal npm install, npm run build and rebuilt production workflow test pass. Corresponding-source files are not loaded into runtime cache.

## Corresponding source (AGPL3)
The application links visibly to this page. Download `extract-sources.py`, `source-index.json` and all30 `source-part-01.json` through `source-part-30.json` alongside one another. Run `python extract-sources.py ./source-output`, then in that directory `npm install --ignore-scripts --no-audit --no-fund` and `npm run build`. Exact installed runtime dependencies are pinned; esbuild0.25.0/acorn8.14.0 are build tools. Editable application/source/adapters and the literal dependency files accompany the app. The precompiled global.css is supplied and its original index.css/Tailwind config/css.mjs are also included for regeneration using pinned PostCSS/Tailwind. No runtime network or database is needed.

Source parts are literal UTF8 JSON file maps, not encoded images/binaries. Their SHA256 and each reconstructed file hash are in source-index.json. Some empty .png/.jpg markers exist solely for the explicitly empty media import loader, not as original images.

Full terms: LICENSE.txt and NOTICES.txt. Original-source hash/Gitblob proofs and exact adaptations: SOURCE.json. Behavioral versus visual acceptance: VERIFICATION.json.
