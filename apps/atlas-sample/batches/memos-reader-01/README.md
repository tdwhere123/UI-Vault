# Memos · 本地便笺时间线阅读

固定原 MemoView / MemoHeader / MemoBody 阅读卡，原 Markdown 正文引擎、长文测量展开、标签过滤与时间戳便笺导航。三条中文文本为明确虚构的本地 fixture；空附件、零评论、无当前账号，不是完整 Memos 服务。

可展开/收起长文、点击原正文标签筛选、点击时间戳进入单条、返回全部。原只读查看结构与 CSS 保留。原 EditSession 保存/草稿/上传/录音链本轮不接入，不替换为新 textarea，不显示虚假的编辑、发布或评论成功。原主体没有被换为 Home 空壳，也没有删除照片冒充原真实用户时间线。

图片、HTML、数学、Mermaid、代码高亮、远程预览等不在固定 fixture 中，未使用引擎明确裁剪；原正文解析器和标签机制保留。URL 一律拒绝，内容不可编辑，不访问网络、存储或后台。原字体栈自然系统回退，没有拉取字体或媒体。

固定源码与版本差异见 SOURCE.json；根 MIT、全部实际包 MIT/ISC，以及编辑器内嵌 Lucide-static 的原完整 ISC 通知见 LICENSE.txt。公开仅7份运行/说明/许可文本，完整原件和适配/构建/测试在本地，不声称已上传源码ZIP。
