# React Flow adaptation
Source https://github.com/xyflow/xyflow at 1bc405cd113618c17fd181b931a9fe573bec9fee. Original MIT notice retained. Runtime is pinned by deps/package-lock.json and dependencies are listed with notices from actual bundle inputs.

The original official React example implementation and original local fixture nodes/edges are preserved. Layouting DevTools panel was omitted. Added a thin full-height host, guidance, system fonts and restrained rounded-node/panel styling; this is an interaction primitive showcase, not a completed Exodus product or a claimed original official branded page. No network services, saving, account connections or agent execution. Some graph/dataflow functions overlap SpatialBoard, but this is a different engine and implementation, not five new unique product concepts.

Verification: production IIFE build, node --check, opaque-origin JSDOM with layout/ResizeObserver stubs; all five mount without console errors or fetch. Auto-layout orientation changes node transforms; synthetic connector mousedown/move/up adds a node and edge; nested children hide and restore; keyboard movement moves a floating node and changes its edge path; editing text propagates uppercase into result nodes. Synthetic mouse events and DOM geometry stubs do NOT certify actual pointer/drag geometry, responsive layout, visual styling or accessibility. Real-browser visual and pointer acceptance remain pending.
