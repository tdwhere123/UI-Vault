把证据放在文字旁边

一篇关于阅读节奏、图表与不确定性的研究札记

注意力 · 证据 · 尺度 · 结语

一页文字不必把所有声音都放在同一条线上。

本演示原创题记

一、让主线保持安静

当我们读一份长报告，最难的往往不是识别每个词，而是在连续的信息里保留一条可以追踪的线。正文负责推进判断，旁注负责保存可以暂时放下的细节。这里保留上游的 label → checkbox → sidenote 相邻结构。宽屏旁注位于正文旁；窄屏由 CSS checked 规则展开。两者并列，而不是相互打断。

这并不意味着把重要限制藏起来。与结论直接相关的前提应该留在正文中。边注更适合定义、来源补充，或者一条不必立即追索的解释。

在助手的长回复里，同样可以先说明判断，再把计算口径放在旁边。读者决定何时进入细节，而不必先穿过所有细节才能找到答案。

二、让图像解释一个问题

下面用一组虚构数据说明：数量相近，阅读顺序却可能改变我们对变化的感觉。示例 A、B、C、D 的数值为 12、19、16、27。它们只用于演示排版，不来自用户数据或外部调查。图表只需要解释这一个问题，不必同时证明整个故事。

一个清楚的图注还应该指出这张图没有说明什么。没有样本定义，不能把这四个数称为增长率；没有时间口径，也不能把连接线解释为时间趋势。

文字与图形相互靠近，能减少在页面上来回寻找解释的负担。但靠近不是证据本身，证据仍要来自可复查的过程。

三、给不同尺度留出空间

有些信息适合窄而长的阅读线，有些适合横向展开。这是上游不编号 marginnote 的另一种原生机制，与自动编号 sidenote 同属一个文章场景。在同一篇文章中使用两种宽度，不必意味着两套视觉语言。

宽图提供一次暂停。随后回到正文，读者仍能沿着前面的线继续。这样的节奏比在每个段落中加入卡片和按钮更适合持续阅读。

四、把限制写清楚

这篇演示保留了 Tufte CSS 的文章、题记、边注与全宽图结构，但字体和内容已作明确替换。它展示的是一种阅读组织方式，而不是某份真实报告的视觉复刻。

好的研究说明不只有结论。它还应当让人知道结论从哪里来、哪些部分可以复查，以及哪些部分仍不能确定。
