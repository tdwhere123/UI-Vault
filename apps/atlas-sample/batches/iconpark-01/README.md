# IconPark original multicolor selection

One series of 94 original SVG glyphs from ByteDance IconPark at commit `8dc132da4c85671ba6a5962c87aa2bdafbf158e9`, Apache-2.0. The exact source geometry/colors remain unchanged. Original names, Chinese titles, categories, tags and author credits are preserved. 24 English names exactly overlap previously collected icon sets; semantic overlap may be larger. This is not 94 new interaction components or unique semantic concepts.

The lightweight gallery UI is an original adaptation, not an upstream official component. It supports Chinese/English/tag search, category filtering, pages of at most 24 thumbnails, and selected original SVG/author/source inspection. Browser CSS changes only display scale, never SVG paths, geometry or fill/stroke data. Raw source is read-only, with no clipboard API, copy button, export, automatic download or external navigation. No backend, network, storage, timers, image files or third-party runtime dependencies.

Publish index.html, runtime.js, runtime.css, ORIGINALS.json, LICENSE.txt, ATTRIBUTION.md, PROVENANCE.json and this README together. ORIGINALS.json is an actual UTF-8 public artifact containing the 94 unmodified SVG strings and original metadata, not a missing ZIP link. Runtime embeds the same data and does not fetch that JSON, so detail browsing works offline. Full Apache license/copyright and all author credits are shipped. Code/build/tests and the independent audit are in the local delivery/source directory only; no public source download is implied.

Build locally with `python build.py` from the adaptation work directory. When rebuilding from copied source elsewhere, set `ICONPARK_UPSTREAM` to an official checkout at the fixed revision; the build requires original source files for verification. run `node test.mjs` with the JSDOM path specified therein; package with `python package_delivery.py`. Build verifies all 94 hashes against original checkout source files and the strict SVG shape/attribute allowlist. Tests compare every rendered thumbnail's original SVG DOM attributes/geometry/paint, verify 24/24/24/22 pagination, search/filter/selection/raw-source equality, malicious search text, reset and pagehide teardown. Eval/Function/Worker/network/clipboard/storage/timer calls are trapped and remain zero. SVG source safety was independently audited against upstream metadata and files.

No visual acceptance is claimed. Responsive pixel layout, actual browser rendering, and native keyboard activation still require visual review. Native buttons/labels and read-only textarea semantics are present; tests cover DOM state and button actions, not browser screenshots.
