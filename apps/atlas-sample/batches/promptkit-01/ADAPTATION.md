# Prompt Kit × Exodus, 10 families

Original source: https://github.com/ibelick/prompt-kit at 5a9496635cc0e1bf7679fe2a9e35d9b36b99c08a. Full MIT LICENCE.md retained as LICENSE. The original license includes a stray `app/page.tsx` suffix; preserved without silently rewriting upstream legal text.

All 10 are standalone IIFEs and independent entry routes; load only the selected detail. Do not preload them on main cards. JSX parser is only in its own ~450 KB bundle; other bundles ~220–275 KB. Original Prompt Kit component implementations preserved byte-for-byte except Source's two Google favicons replaced with authored inline SVG document symbols. No remote fonts/assets or backend needed.

Ten counts mean ten component families, NOT ten new functional categories or complete Agent applications. Existing Vercel AI Elements and assistant-ui contain related concepts. source-index hashes find exact copies; manifest records semantic overlaps. Loader's 12 variants are one family; FileUpload+PromptInput form one composer family; TextShimmer is part of ThinkingBar, not separately counted. ChainOfThought's nested per-step accordions and Steps' aggregate run accordion are independently implemented upstream components, not color variants. ToolUI was not added because successor assistant-ui migration would duplicate sources.

Original demos retained: ChainOfThoughtBasic, StepsBasic, ResponseStreamTypewriter. FileUpload demo retains original picker/drop/file chips and simulated 2 second send. To correct upstream misleading 'Stop generation' label, disabled repeat send during simulation and renamed the tooltip/aria-label. File input accept is a picker hint, not security validation; no upload occurs. User files remain only in page memory. No real model, repository scan, storage or file transfer.

Other wrappers call original public components with local state: JSX editing/reset; ThinkingBar start/stop/details; SystemMessage policy/dismiss/restore; FeedbackBar voting/close/reset; Loader variant select/play/pause; Source hover/focus local citation. JSXPreview uses original parser with a strict static tag whitelist, only className forwarded, no expressions, event attributes, style, SVG, resource tags, href/src, custom imports or bindings. Invalid/blocked markup is omitted or explained inline. Sample buttons in JSX are intentionally inert; this is markup preview, not arbitrary code execution. No window.prompt/confirm, eval UI input, popup permission or same-origin required. Source's explicit external links may be blocked by allow-scripts-only sandbox; hover/focus preview still works without leaving page.

Runtime CSS compiles original globals/theme and Tailwind classes, plus external rounded preview shell. System-font fallback replaces website fonts. Loader starts paused and mounts only one selected variant; ThinkingBar starts stopped. Prefers-reduced-motion CSS suppresses animations. ResponseStream starts when detail mounted and can replay.

Validation: build, JS parse, 10 JSDOM mounts and state transitions; no browser visual/pointer QA. JSDOM cannot verify actual animation appearance, drag physics, native file chooser, CSS layout or source hover positioning. See VERIFICATION.json. Do not label visually verified.
