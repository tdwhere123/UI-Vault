# Fluent UI System Icons Color · selected 100
100 selected professional color base icons, original 24px asset per base. One icon series, NOT the complete library and NOT Fluent Emoji. The selection spans documents/data, communication/collaboration and navigation/tools; original names are preserved. The three browse categories are explicitly curator-defined, not upstream metadata.
Original assets © Microsoft Corporation, MIT. Complete license and upstream NOTICE are published in notices/. NOTICE includes replace, avocado and yargs tool-license notices; these are upstream tooling acknowledgments, NOT runtime packages executed in this browser. Our original browser shell has a separate MIT notice. No whole-source attribution is reassigned.
All source files were fetched from official raw paths at fixed commit e15fc0de25fab983e3e42bac8798be69a85c23bf. ORIGINALS.json preserves source path, complete UTF-8 text, SHA-256 and Git blob hash. The available recursive repository tree is truncated and is NOT treated as a complete inventory. Selection uses the complete official icons_color.md index; known recorded Git blobs are cross-checkable, and all assets originate at explicit fixed raw URLs.
Original gradients and filter IDs MUST remain isolated: each SVG is rendered through its own image data URI, using encodeURIComponent on the original UTF-8 SVG text. This is readable original vector source, not binary/base64 packaging. No SVG is inserted into the host DOM. No paths, gradients, opacity, colors or geometry are altered. Strict SVG whitelist checks reject scripts, foreignObject, images, href and external resources; all permitted url(#id) references resolve inside that same SVG. Local filter elements are retained.
The browser supports name search, curator category filter, 24-per-page results, detail enlargement, original source/hash display and readonly SVG text. No clipboard/download/storage/network APIs. Only the explicit original SVG data URIs may be assigned to Image.src.
Tests inspect all 100 entries across five pages: both grid and detail image src decode exactly to original SVG text, including gradients, and readonly source matches. XML tags/attributes/references are validated at build time. This does NOT establish rendered gradient/filter fidelity or pixel-level browser visual acceptance. Visual QA not run; no screenshot/cover created.
Reset, repeated pages, malicious search, and exit with zero timers/global listeners/external requests are verified. Original images are public in ORIGINALS.json. Adapter build/test source is delivered locally in source/, not falsely advertised as a public download service.
