# ElevenLabs UI · four Exodus preview families

Upstream: https://github.com/elevenlabs/ui @ `3a28ebab197f8cfa599934f52db12ad1396e54f4`. Root MIT ©2025 Eleven Labs Inc. retained. Original Matrix, Waveform/AudioScrubber, AudioPlayer, TranscriptViewer, use-transcript-viewer and helper primitives are unchanged; source-index records each original SHA256. New wrappers, local fixtures, keyboard affordance and page presentation are separate files.

## Honest scope

Four families: dot-matrix status display; mathematical waveform seeking; local test-tone playlist; preset aligned-text reader. They are not4 functioning AI services. No microphone, ElevenLabs SDK runtime, API key, cloud requests, real transcription, downloaded audio, remote voice identity or binary publication. VoicePicker/Orb/WebGL and mic/live-recording components are not included. Dot matrix frames/digits,3 waveform fixtures and3 test tones remain variants within these4 families.

Matrix preserves original animation patterns; 7×7 cells only, default paused, hidden-page pause, system reduced-motion styles. Waveform preserves original canvas renderer and pointer seek, with a wrapper-level arrow-key handler and reset. Signal is generated by a mathematical formula, not recorded audio. Not a trim editor or real audio analyser.

AudioPlayer uses its native original HTMLMediaElement and original progress/speed/button APIs. A wrapper conditionally mounts its slider only when a finite positive duration exists, avoiding the original zero-range initial NaN position. Track titles, pause,seek and speed respond to actual media element state; playback failure is displayed. No faked playback clock. Three original non-speech test-tone WAV blobs are synthesized in browser by a small PCM sine/envelope formula. No base64 or uploaded audio. Each8seconds at8kHz mono16bit, modest amplitude, no autoplay. Blob URLs are revoked on unmount, audio pauses when the document is hidden. A single provider polls its audio clock per original rAF logic only while this detail exists; do not preload it on main cards.

TranscriptViewer uses original character-alignment parser, time tracking/highlight and scrubber. Text and equal-spaced character times are authored static fixtures explicitly labeled unrelated to the audible tones. This is **not speech recognition**, nor an accurate transcription of tones. Supported renderWord slot adds keyboard-accessible buttons that seek the real audio element to each fixture word's supplied time. Test-tone selection remounts the original viewer. Runtime WAV MIME uses audio/wav (upstream TypeScript AudioType omits WAV, wrapper casts only the type; no original component changes).

## Host integration

Every route has complete explicit head/body and exact runtime.css/runtime.js tags. Independent IIFEs prevent loading the other routes. Only `audio-player` and `transcript` set `needsLocalMedia:true` and `runtime.allowLocalMedia:true`. Their host must explicitly add **media-src blob:** while preserving the rest of CSP and iframe `allow-scripts`. No remote address, data media, same-origin, popup or microphone permission is needed. Matrix/waveform keep original default CSP with media blocked. This is a controlled host policy choice approved by parent; these artifacts do not alter the shared host.

No source ZIP download link should be displayed until actually uploaded. Source ZIP remains local and includes code+lockfile+licenses, not audio binaries. Source and font names inherited in globals are system-font fallbacks; no font downloads.

## Validation limits

Build/JS parse, four JSDOM mounts, Matrix frame state changes, pointer and keyboard seek, test tone Blob size, playback/pause/rate/seek/track switches, transcript highlight/word seek, hidden pause passed. Media and Canvas APIs were stubbed for JSDOM; tests do **not** prove browser decoding, audio output, timeline gesture quality, CSP enforcement or actual pixels. Separate WAV header/PCM sample test confirms generated file structure, not audible output. See VERIFICATION.json and WAV-VERIFICATION.json. No real browser visual/audio QA yet.
