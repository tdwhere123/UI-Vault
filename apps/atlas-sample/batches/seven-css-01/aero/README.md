Original 7.css0.21.1 fixed-revision official documentation selections, 29 original examples across10 original partials: glass frame, titlebar, statusbar, tabs, buttons, checkboxes, option/radio buttons, groupbox, collapsible and treeview. One showcase family, NOT the full25-component docs, not a desktop/window manager. Original example HTML and SCSS retained except globally unique id/for/aria-controls prefixes perexample and five PNG control glyph roles replaced by exact existing Lucide0.468.0 SVGs (minus/square/circle-help/copy/x). Original window buttons remain nonfunctional presentation, not fake minimize/close. Original tabHandler algorithm retained; managed local listeners guard disabled tabs and clean up on exit/error. Hidden pauses CSS animation, reduced motion disables transitions; no continuous JS jobs. Explicitly omitted body demo with embedded dog JPEG, slider/spinner bitmaps, custom bitmap scrollbar, photo backdrop, external analytics/share/badges and copy-to-clipboard code. System Segoe UI/Calibri/Noto Sans/sans-serif stack only, no proprietary font files shipped; actual font availability varies. Frame sits on disclosed plain host backdrop, not original flower photograph. EJS source-example wrappers flattened to rendered original examples, no highlighted code or Copy buttons. CSS compilation/build-only Sass/EJS packages do not execute in runtime. No network/storage/clipboard/forms external action. Actual563 compose and loader, tab mousedown/focus/disabled, native checkbox state, details property, hidden/resume/late failure/early missinghost/oldnode exit tested in JSDOM; not native pixels/glass blur/font acceptance.
