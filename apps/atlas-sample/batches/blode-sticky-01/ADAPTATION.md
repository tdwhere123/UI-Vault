# Blode · Sticky notes

Existing candidate blode:sticky-notes. Fixed MIT source:
https://github.com/mblode/experiments/tree/d4baef572c4e692dcfe5f3a1e424e641d6013b18/app/sticky-notes

Preserves original 25-note stack, pressure-aware perfect-freehand SVG drawing, five pastel colors, edge detection, directional peel distance/momentum completion, Zustand note/history state, springStep/paperEase, and original vertex/fragment shaders. Shader files are byte-identical to upstream. Not a Path2D rewrite, fake screenshot, CSS approximation or substitute curl. Original rendering route remains SVG serialization -> local Blob -> Image -> canvas draw -> Three CanvasTexture -> original WebGL shader. No original artwork/media was replaced or downloaded; all drawing starts as local empty notes.

CSP correction: the catalog's default img-src explicitly allows data: and blob:, so creating a local SVG Blob image needs NO policy expansion. This is not embedding/uploading external binary data or base64-wrapping assets. connect-src remains none; no worker, eval, media capability, font/image download or API added.

Scoped repairs: texture hook uses finally to revoke Blob URLs on success/error, pending Image cancellation, unmount disposal and generation tokens to reject stale asynchronous completions. disposeTexture invalidates pending captures. Stack refuses to enter peel when texture capture fails or drag/unmount has already ended. Pointer cancellation and document hidden cancel active peel and dispose texture. Mesh geometry/material are explicitly disposed on unmount. Stop unmounts the view; Reopen preserves original temporary in-memory notes. Pagehide unmounts root. Reused source SVG path helper is copied directly; no broad application barrel is imported. Color buttons receive accessible names. React 19.2 satisfies Fiber 9.6.1's declared >=19 <19.3 peer; optional native/Expo peer packages were intentionally not installed. All installs used ignore-scripts.

Honest availability: WebGL2 preflight releases its temporary context. If unavailable, a visible message explains that drawing still works but curling cannot run. Edge interaction also says no simulated curl. A React error boundary reports renderer-start failure instead of claiming a working GPU preview. Actual GLSL compile/runtime failures and browser GPU appearance have NOT been verified here. The shader's normal render loop exists only during an active textured peel; cancel/hidden/stop removes the Canvas.
