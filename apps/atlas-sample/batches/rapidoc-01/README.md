# RapiDoc original offline OpenAPI reader

One original RapiDoc webcomponent UI, not a custom documentation shell or ordinary schema card. Correct npm package name is **rapidoc** (not rapi-doc). Fixed version12.1.1, official release tag rapidoc@12.1.1, commit **1cea8311b25670dc78e4a0fb5cbc8016d43a6392**. npm src/rapidoc.ts, styles/font-styles.js and LICENSE.txt match that release byte for byte; see local release-evidence. Research HEAD is not substituted for package provenance.

The exact upstream bundled distribution is imported without rewriting its parser, templates or component algorithms. Original Lit shadow-root styles, navigation, advanced search, request/response examples, status-code tabs and schema trees are retained. Only a brief host caption supplies context. Atlas Document API is original synthetic OpenAPI3.0.3 fixture text with five operations, two tags and four local component schemas. It describes no actual service and contains only internal #/ references; no URLs, externalDocs, remote examples or callbacks. Original loadSpec(object) performs the parsing and schema resolution. Host validates local references before calling it; no URL/file loading is offered.

## Offline and read-only scope
Explicit false settings: allow-try, allow-authentication, persist-auth, allow-server-selection, allow-spec-url-load, allow-spec-file-load, allow-spec-file-download, mock-server and MCP. show-curl-before-try is false. load-fonts=false is supplied defensively, but v12 has no active loadFonts property or automatic Google-font loader in this source; its original font styles use CSS family variables. Host supplies system-ui/monospace, no font assets. Original bundle may retain dormant fetch/resource/export implementation, but no configured path invokes it.

Host observes open shadow roots and disables original Copy buttons with an explanatory title. Capturing click/submit prevents clipboard/external navigation or submission; external anchor destinations are removed. The original component remains navigable internally. Stale disconnected shadow-root observers are pruned on traversal, not retained indefinitely; all host observers are disconnected on exit. This is a read-only offline preview, not a fake successful request console. No network, API credentials, Worker, storage, clipboard, file upload/download or external-link action is performed.

## Lifecycle adaptation
Host pagehide increments the original version-specific `_specLoadSeq` generation, which loadSpec and afterSpecParsedAndValidated actually check. This invalidates original in-flight parsing without introducing another parser. The original advanced-search debounce `timeoutId` is cleared. An instance wrapper delegates initIntersectionObserver only while the host is open: the original deferred attribute-change initialization otherwise could create one observer after initial pagehide. Original disconnectedCallback still performs its own normal observer/global-listener cleanup. These are explicit host-level, version-sensitive lifecycle adaptations; no upstream bundle/source editing. Updating RapiDoc requires revalidation.

## Verified behavior and honest limits
Eight actual parser/DOM tests verify five operations/two tags, real nav filtering, advanced search with special literal queries (`[`, `/`, `<img ...>`), response Draft→Published example selection, schema/example tabs, request example selection, 201/422 response statuses, schema aria-expanded toggling, repeated tabs, disabled copies and prevented submission. No image element/request is introduced by search text. UI actions are dispatched to actual original elements; the model/parser is not mocked.

Two interruption tests stop initial load and reload while the original async `loadSpec` is still loading, then let parsing settle. Generation increments and late results do not replace the pending state or emit spec-loaded. Observer/global-listener/timer counts reach zero. Main workflow also tears down while advanced-search debounce is pending. Runtime eval/Function/fetch/XHR/Worker/WebSocket/BroadcastChannel/storage/clipboard/window.open and Image.src attempts are trapped: zero calls. Function trap preserves original prototype through Proxy to avoid breaking legitimate type checks.

Tests run in JSDOM. Node's native structuredClone is supplied; IntersectionObserver/ResizeObserver, scroll methods and dialog.showModal/close are mocks because JSDOM lacks browser layout. CSS.escape is a limited harness substitute used for these known fixture IDs. No actual pixels, mobile/responsive design, real scroll-position geometry or native keyboard activation accepted.
