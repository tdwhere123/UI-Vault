# Chart.xkcd · Original Plan / Reality

Original complete examples/index.js Line scene: Monthly income of an indie developer, Plan/Reality ten-month values, original monotoneX paths, axes, labels, handdrawn filter, legend and mouse tooltip. Original source engine preserved except two explicit adaptations: utils/addFont.js replaced by no-op to omit unconditional embedded base64 WOFF; addLegend imports an owned timeout adapter so its original 10ms deferred geometry work is canceled on hidden/exit and caught on failure. Original supported fontFamily option uses system-ui; HTML Google ZCOOL stylesheet omitted. Original xkcd glyph typography is NOT reproduced. No binary/font encoding is published. Root source contains original font helper privately only for provenance, never bundled or offered as public asset. Other changes are a bounded host: positive-width defer, responsive max-width, hidden clears transient hover chart then visible restores same fixed data, resize rebuild, error status and exact disposal of D3 handlers and legend timeout. This original chart has no drawing animation; reduced motion has same static behavior. It is a fixed illustrative fixture, not user financial information or live data. Source entry selects Line directly, so dayjs is not an actual runtime dependency; 10 parsed packages are enumerated from esbuild inputs: 9 D3 packages emit runtime bytes; internmap is parsed but entirely tree-shaken according to outputs.inputs, with ISC text conservatively retained (10 license texts, not 10 emitted runtime packages). Tests run real D3 path/tooltip code with 400px width and synthetic getBBox/getComputedTextLength/mouse coordinates, not native geometry, visual filter, pixel or accessibility acceptance. No keyboard tooltip support is claimed.
