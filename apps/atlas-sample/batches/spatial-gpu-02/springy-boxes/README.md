Original complete effect retained; no images, fonts, backend, media, fake canvas substitute or screenshots.

Shared isolated host tracks WebGL allocations and compile/link status; failures/context loss are visible and stop. Hidden unmount releases resources, visible return rebuilds original scene; stale callbacks cannot resume disposed work.

Actual554 compose/default CSP, GL command/status stubs, DOM and deterministic bounds tests. Native GPU compilation/pixels remain unverified.

Original35 boxGeometry fixtures,6colors,random transforms,mass20/tension150/friction50,3-second delayed spring update,original lights/shadows/camera retained. React18.3.1/Fiber8.17.10/Three0.172.0 match original sandbox declarations; wildcard @react-spring/three pinned9.7.5, not claimed exact upstream lock.

Original interval now returns clearInterval/api.stop. Reduced motion sets spring skipAnimation and Fiber demand rendering, with no3-second interval.

Fiber8.17.10 unmount500ms delay replaced by microtask cleanup; renderer.dispose added. Last inactive root explicitly stops/resets global Fiber loop so host cancellation does not leave running=true across remounts. Original rendering/geometry/shader generation unchanged.

Spring rafz queue cleared after unmount; asynchronous graphics failures reach teardown outside spring frame callback. All callbacks/resources have ownership guards.

Normal text module boundary: runtime-three.js exports original Three0.172.0 API as iframe-local AtlasThree; runtime.js imports that API via compile-time shim. Each UTF8 file <700KiB; production runtime.scripts loader composes in order. No binary wrapping or CSP expansion.

Tests run actual original Three rendering code against mocked WebGL functions and shader success/failure reports, not a replacement renderer. Recorded GL draw/matrix commands are not proof of native GPU pixels. Geometry bounds/ResizeObserver are mocked. Normal/reduced/unsupported/shaderfail/latefail/contextlost/earlyexit/missingroot are focused lifecycle branches; normal checks hidden/zero-size recovery redraw and stale callbacks. Spring cycle mode waits a real3-second original timer and checks changed finite model-view matrices. Vanta normal checks non-empty original line buffer and real mouse event changing original camera target. Final allocation deletion, RAF/timer/observer and listener ledgers checked. Public files are runnable built assets with full notices; private build workspace is not promised public.

Commands: npm ci --ignore-scripts; node build.mjs springy-boxes; node test.cjs normal springy-boxes. Styles are original Spring CSS plus small host status/viewport layout, or Vanta full-container target. No native browser or screenshot validation was performed.
