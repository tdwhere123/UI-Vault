# Original CSS component family, local gallery

This is a host-authored minimal gallery of four fixed original augmented-ui v2 corner-region mixins, not an original complete upstream application. Original CSS remains byte-identical at the beginning of runtime.css. Local size/border controls only update documented CSS variables; shapes are drawn by original CSS. No invented workflow, remote data, images, fonts or storage. Four mixins are one family entry, not four entries or a full mixin-suite claim.
