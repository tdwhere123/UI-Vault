## Scope
Both original GPT-5 article paragraphs, title, quoted description, clock metadata, two original links, pill SmoothButton, black rounded Radix popover with arrow, and original Motion animation retained. Intro naturally labels the text as an upstream article demonstration, not current product facts. Original inaccessible span trigger minimally changed to same-class button with accessible label. No iframe, remote image, thumbnail, fake player, backend or fetch.

Links remain their original URLs with target=_blank and rel="noopener noreferrer". The unchanged atlas sandbox cannot open popups. UI states that limitation; tests inspect URLs/attributes but never navigate or transmit them.

Original methods restored. This scoped boundary is intended only for the isolated preview document, not insertion into a shared host document. Legacy matchMedia.addListener callbacks separately tracked and removed (native legacy APIs do not necessarily delegate to EventTarget.addEventListener). Observers tracked while active and disconnected on exit. React root is unmounted before deferred release of delegates, global handlers, observers and pending timeout/rAF. Old detached triggers do not revive it. Scope contains no public test globals.
