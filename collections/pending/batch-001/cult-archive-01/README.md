# Cult UI source archive 01

22 source candidate groups, zero browser acceptance, zero build claims. Official repository MIT (Jordan-Gilliam) preserved. Official registry JSON includes exact demo/component source and declared npm/registry dependencies. Shared shadcn primitives, utils, original monorepo package manifests and pnpm lock archived separately. The lock is not a standalone ready-to-build npm project.

Source collection emphasizes interaction systems and marketing sections: AI instruction manager, prompt library, multi-view drawer, staged onboarding/wizard, expanding toolbar/surface, analytics hero, code/network section, movable panels, glass shader. Folded decorative card is not counted. Onboarding/wizard variants are a single family. Cross-source deduplication and visual quality remain pending rather than asserted.

External photographs, media, logos, and fonts were not downloaded. Dependency licenses remain their own; shader/brand assets require additional checks before runnable public delivery. Read manifest imports and registry dependencies for integration. No Codex, shared browser, or production tree used.
