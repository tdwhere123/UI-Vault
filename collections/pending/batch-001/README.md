## 如何查看

- [统一候选清单](candidate-index.json)按唯一 ID 指向各来源 manifest 与源码 ZIP。
- 各目录的 `manifest.json` 保留固定上游版本、许可、依赖、原件位置、改动与已知缺口。
- `source-archive.zip` 或 `archives/*/source.zip` 是原件/适配源码包，**不是所有候选都能直接运行**。先看其构建状态、资源缺口与依赖说明。
- 许可原文与依赖通知保存在相应源码包，部分也在目录中直接提供。
- `UPLOAD-MANIFEST.json` 记录本次归档文件大小和完整性摘要，仅用于后台核验。

## 边界

这里是研究与学习用的候选档案，不是“新增 93 个已验证精品”的承诺。跨来源视觉相似性仍需后续去重；同一组件换颜色、框架或示例不拆开计数。浏览器受限期间继续保存源码，不把静态 import 检查当作安装构建，不把构建成功当作视觉与交互验收。

已排除许可存在冲突的 Cruip 模板；Fancy 两项衍生许可待核滤镜不在公开 ZIP 中；UI Layouts 的 Cruip 卡片与未核许可 gist 滚动组件不在此构建批中。远程演示照片、品牌与视频不因代码许可自动获得授权，缺口或明确本地替换均记录在各清单。

本目录不被 GitHub Pages 导出，不增加首页加载量，也不改变当前图鉴计数。通过后才逐批接入正式素材目录。
